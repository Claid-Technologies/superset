  • 1
    Reply count

    Every non-deleted comment on the page, across all threads and versions. Amber whenever unresolved threads remain — the “this still needs someone” signal; gray once everything is resolved. Screen readers get the full phrase (“5 replies, 2 open threads”), and pages with zero replies render no chip at all.

  • 2
    Latest reply

    Newest comment on the page: avatar, author, and a one-line snippet (the server sends only the first 240 characters). Agent replies show the bot mark and the Agent byline, same as the comments panel. Clicking anywhere on the card still opens the page, where the full threads live.

  • 3
    Recency

    Compact relative time of that last reply (formatCompactRelativeTime), so a stale conversation reads differently from one that moved two minutes ago.

How it’s wired

One query, no fan-out

page.list gains two correlated laterals: an aggregate for commentCount / openThreadCount, and a limit-1 for the latest reply. The gallery still makes a single request; nothing fetches per card.

Additive shape

New fields ride the existing RouterOutputs type, so mobile, the CLI, and MCP pages_list pick them up without breakage — mobile’s row type derives from the router output.

Localized

The two new plural strings (“# replies”, “# open threads”) are hand-translated in all 17 locales, reusing each catalog’s established nouns for “reply” and “thread”.

Open questions

Hover depth.

The strip shows one reply. Worth a hover card with the last two or three, or is one line plus click-through enough? The query could return three as cheaply as one.

Amber semantics.

Right now amber means “any unresolved thread.” An alternative is “someone replied since you last opened it,” but that needs per-viewer read state we don’t track yet.

A “needs reply” filter.

Once open-thread counts are on every row, a filter chip beside All / Pinned / Team is a small follow-up. Skipped for now to keep this change tight.

Pin a comment on any element here — the toggle, a card, a strip — and hand it to the agent; this page is watched from the branch.
