## Sentry webhook → agent on the bug

When Sentry fires an alert, file a task and start a cloud workspace with an agent investigating it, in two SDK calls. (In production, verify the Sentry signature header before trusting any payload. That part is omitted here for clarity.)

```ts title="sentry-webhook.ts"
import { Hono } from 'hono';
import Superset from '@superset_sh/sdk';

const app = new Hono();
const client = new Superset();
// reads SUPERSET_API_KEY + SUPERSET_ORGANIZATION_ID from env

const ENVIRONMENT = process.env.SUPERSET_ENVIRONMENT; // id or name; omit for the first with repositories

app.post('/webhooks/sentry', async (c) => {
  const event = await c.req.json();
  const { title, web_url: sentryUrl, culprit, short_id } = event.data.issue;
  const slug = `sentry-${short_id.toLowerCase()}`;

  // 1. File a task so the bug shows up in the dashboard
  const task = await client.tasks.create({
    title: `[Sentry] ${title}`,
    description: `Triggered by ${culprit}\n\nSentry: ${sentryUrl}`,
    priority: 'high',
    labels: ['sentry', 'bug'],
  });

  // 2. Start a cloud workspace on its own branch with an agent on it.
  //    The agent launches as soon as the sandbox boots; this call
  //    returns right away with the workspace still provisioning.
  const workspace = await client.workspaces.create({
    environment: ENVIRONMENT,
    name: slug,
    branch: slug,
    agent: 'claude',
    prompt: [
      `A Sentry alert just fired:`,
      `  Title: ${title}`,
      `  Culprit: ${culprit}`,
      `  URL: ${sentryUrl}`,
      ``,
      `Reproduce the failure, fix it, push the branch, and update task`,
      `${task.id} with what you found.`,
    ].join('\n'),
  });

  return c.json({ ok: true, taskId: task.id, workspaceId: workspace.id });
});

export default app;
```

What just happened, end-to-end:

- The task lives in the cloud and shows up in the dashboard for everyone.
- The workspace is a sandbox in Superset's cloud with the environment's repositories checked out on the new branch. Nobody's machine has to be online, and a human can open it from the desktop app to take over if the agent gets stuck.
- The agent runs inside that sandbox with the prompt above.

## Burn down the P0 backlog overnight

Pick up every urgent task in the queue and start a cloud workspace with an agent on each one. Each gets its own sandbox, so they run in parallel without sharing a checkout.

```ts title="burn-p0s.ts"
import Superset from '@superset_sh/sdk';

const client = new Superset();

const p0s = await client.tasks.list({ priority: 'urgent', limit: 50 });

const workspaces = await Promise.all(
  p0s.map((task) =>
    client.workspaces.create({
      name: task.slug,
      branch: task.slug,
      agent: 'claude',
      prompt: [
        `Pick up task ${task.slug}: "${task.title}".`,
        ``,
        task.description ?? '(no description; read recent changes for context)',
        ``,
        `Investigate, make the fix, run the relevant tests, push the branch, and`,
        `update task ${task.id} with a one-paragraph summary of what changed and why.`,
        `If you can't make confident progress in ~30 minutes, leave a comment with`,
        `where you got stuck and stop.`,
      ].join('\n'),
    }),
  ),
);

console.log(`started ${workspaces.length} cloud workspaces across the P0 backlog`);
```

Run it from a nightly cron and you wake up to a branch per bug. Sandboxes bill while they exist, so delete the ones you're done with (`client.workspaces.delete(id)`).

## Supervise an agent from a script

Launch an agent, watch its screen, send it a follow-up, and clean up. This is the loop a CI job or an internal tool would run.

```ts title="supervise.ts"
import Superset, { type CloudWorkspace } from '@superset_sh/sdk';

const client = new Superset();
const sleep = (ms: number) => new Promise((resolve) => setTimeout(resolve, ms));

async function waitUntilReady(id: string): Promise<CloudWorkspace> {
  for (;;) {
    const workspace = await client.workspaces.retrieve(id);
    if (!workspace) throw new Error(`Workspace ${id} was deleted`);
    if (workspace.status === 'ready') return workspace;
    if (workspace.status !== 'provisioning') throw new Error(`Workspace ${id} is ${workspace.status}`);
    await sleep(5_000);
  }
}

const { id: workspaceId } = await client.workspaces.create({ name: 'dependency-bump' });
await waitUntilReady(workspaceId);

const { sessionId: terminalId } = await client.agents.create({
  workspaceId,
  agent: 'codex',
  prompt: 'Bump every dependency one minor version, run the tests, and summarize what broke.',
});

// Print the bottom of the agent's screen every minute for 15 minutes
for (let minute = 0; minute < 15; minute++) {
  await sleep(60_000);
  const { text } = await client.terminals.read({ workspaceId, terminalId, maxLines: 20 });
  console.log(text);
}

await client.terminals.send({
  workspaceId,
  terminalId,
  text: 'Open a draft PR with the changes that kept the tests green.',
});
```

Terminal and agent calls go straight to the workspace's sandbox. The SDK keeps the ticket for it fresh and wakes the sandbox only when it has stopped, so calls don't extend a running sandbox's session.
